# KAWAKAMI Lab.

同人サークル KAWAKAMI Lab. のサイト(スマホ向けデザイン)。Next.js 15 / React 19。

```bash
npm install
npm run dev
```

http://localhost:3000 で確認できます。

- `app/globals.css` — デザインのスタイル(色・フォントなどのトークンは `:root`)
- `lib/data.ts` — 刊行物・プロフィール・参加イベントのデータ
- `components/lab/` — 各セクションのコンポーネント
- 画像は `Placeholder` で仮置きしています。実際の作品画像に差し替えてください。
